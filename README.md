# TutorHub

TutorHub is a Learning Management System (LMS) built by Solethu Labs.

## Vision

To help tuition centres manage learners, tutors, classes, attendance, payments, recorded lessons, and online assessments from one platform.

## First Client

Sharp Minds Tuition

## Core Users

- Admin
- Tutor
- Learner

## Planned Features

- Learner registration
- User management
- Online classes
- Recorded lessons
- Notes sharing
- Attendance tracking
- Payment management
- Online tests
- Automatic marking

## Technology

Frontend:
- React
- Tailwind CSS

Backend:
- Node.js
- Express.js

Database:
- PostgreSQL
- Prisma ORM
